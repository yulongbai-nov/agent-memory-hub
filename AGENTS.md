# Agent Instructions

This repository is a documentation hub for the Graphiti-based “agent memory” integration across:

- Graphiti service (`graphiti`)
- Copilot Chat (`vscode-copilot-chat`)
- Codex (`codex`)

## Spec-first workflow

Treat these files as source of truth for this repo:

- `.specs/agent-memory-hub/design.md`
- `.specs/agent-memory-hub/requirements.md`
- `.specs/agent-memory-hub/tasks.md`

Keep docs in `docs/` and prefer relative links to files in `repos/` (submodules).
